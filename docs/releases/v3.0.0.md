# GloamCore 3.0.0

GloamCore 3.0.0 adds League Navigator and the versioned data foundation needed
for league-correct guidance on Windows, Android, and iOS.

## League Navigator

- Follow exact Acts 1–10 campaign route steps transformed from the pinned
  Exile Leveling source.
- Select Kill all, Alira, Kraityn, or Oak and see only the matching route
  branch; include the optional Library branch independently.
- Track progress locally and migrate known step IDs when a new league pack is
  activated.
- Search every source gem and see class-correct quest/vendor acquisition,
  act, quest, and NPC. Optionally restrict results to enabled gems in the active
  Build Lab workspace.
- Uses authentic Path of Exile quest and Bandit artwork with explicit source
  attribution rather than generic generated imagery.

## Patch-safe data

- Bundles the current official Grinding Gear Games Atlas `3.29.1` export and a
  pinned Exile Leveling campaign snapshot.
- Verifies file sizes, SHA-256 digests, UTF-8 JSON, schemas, game-version
  agreement, Atlas node identity and symmetric links, campaign directives, and
  acquisition bounds before activation.
- Checks GloamCore's Pages channel automatically while League Navigator is
  open, activates the complete candidate atomically, retains one rollback pack,
  and remains usable from the bundled pack offline.
- A scheduled GitHub workflow discovers new upstream revisions, rebuilds and
  tests them, then opens a guarded review PR. It cannot publish a partial or
  unreviewed source update directly to users.

Craft of Exile and every existing GloamCore workspace remain intact. This
release does not restore the retired full official-trade-listings subsystem.
