# GloamCore 3.4.7

GloamCore 3.4.7 makes copied item modifiers easier to understand in the in-game
Ctrl+D price-check overlay without changing the underlying official Trade query
behavior.

## Improved

- Calculated properties, enchantments, implicits, prefixes, suffixes, crafted
  modifiers, and pseudo totals now appear in clearly labeled lanes.
- Multi-line affixes from Path of Exile's Advanced Description remain visually
  linked while every modifier keeps its own selection and range controls.
- The bounded live seller-price snapshot remains directly below the modifier
  editor and updates with the selected query.
- The overlay follows the active GloamCore theme, including corruption identity,
  contrast, compact-height, empty-state, and error-state styling.
- The public website now shows fresh captures of the current app and price-check
  overlay.

## Verification

- The established 126-file suite with 1,666 automated tests passed for the
  feature commit before release versioning.
- Focused release-identity coverage and the production build pass at 3.4.7.
- The packaged Path of Building engine and unique, rare, and wand Ctrl+D native
  smoke scenarios pass against the exact release executable.

Installed Windows builds can use **Settings -> Check for updates**. Portable
Windows builds and mobile packages still require a manual replacement.
