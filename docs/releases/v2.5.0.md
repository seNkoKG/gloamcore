# GloamCore 2.5.0

GloamCore 2.5.0 delivers a major Build Planner and passive-tree upgrade backed
by the installed Path of Building Community engine.

## Highlights

- Reorganizes the planner into a compact build context bar, persistent
  character statistics, and dedicated Tree, Items, Skills, Config, and
  Calculations workbenches using the GloamCore visual system.
- Adds exact PoB-powered node analysis with offence, defence, blended heatmaps,
  point-depth controls, ranked passive reports, and path-aware delta tooltips.
- Introduces Timeless Lens for Glorious Vanity, Lethal Pride, Brutal Restraint,
  Militant Faith, Elegant Hubris, and Heroic Tragedy.
- Searches official PoB seed lookup tables across one socket or the entire
  passive tree with exact seed ranges, allocation scopes, primary and secondary
  weights, minimum thresholds, and decoded node transformations.
- Restores imported builds, equipment, skills, configuration, passive specs,
  masteries, notes, and the last planner tab after restarting the application.
- Keeps planner state private to the local operating-system user and excludes
  account credentials and OAuth tokens from autosaves and release artifacts.
