# GloamCore 3.4.4

GloamCore 3.4.4 is a data-correctness and resilience release for the PoE 1
campaign, gem finder, market mirror, and economy toolkit.

## Fixed

- Campaign directions, portals, waypoints, Labyrinth steps, crafting recipes,
  quest text, and other pinned route directives now render as real instructions.
  Unknown directives stop pack generation instead of leaking raw template text.
- Royale, unused, internal, and duplicate gem entries are removed from the
  public finder. Duplicate names prefer the record with stronger quest/vendor
  acquisition evidence.
- Campaign progress now uses content-derived step identities, so unrelated line
  insertions no longer move every saved checkmark.
- Remote game packs must advance the semantic PoE version or the explicit pack
  revision. Downgrades and reused identities with different hashes are rejected.
- Integrity-verified poe.ninja evidence remains viewable for up to 24 hours when
  GitHub scheduling is delayed. After two hours it is explicitly stale,
  informational, and unable to drive confidence-sensitive movers or alerts.
- Divination-card expected value uses poe.ninja's per-card price directly rather
  than dividing it by reward stack size again.
- Website and current documentation now match the bounded desktop Trade
  search/fetch behavior and its ten-row limit.

## Update note

Existing campaign checkmarks can reset once when upgrading because older builds
stored positional IDs that contain no recoverable step identity. After this
migration, unchanged route steps retain progress across future pack updates.

Installed Windows builds can use **Settings → Check for updates**. Portable
Windows builds and mobile packages still require a manual replacement.
