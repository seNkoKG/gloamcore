# GloamCore 3.1.0

GloamCore 3.1.0 adds Atlas Command Center to the patch-safe League Command
Center on Windows, Android, and iOS.

## Atlas planning

- Browse and search the complete official PoE `3.29.1` Atlas graph with
  authentic GGG Atlas sprite sheets, pan/zoom, node stats, reminder text, and
  flavour text.
- Click any node to allocate its shortest connected route. Point cost is exact,
  official gateways are graph edges, and `Unwavering Vision` grants its
  official 20 points only after the path can afford reaching it.
- Refund a node safely; any dependent branch disconnected from the official
  root is removed, and a refund that would leave the remaining allocation over
  budget is rejected.
- Set the number of Atlas points actually earned instead of assuming a complete
  Atlas, with the validated pack's official total as the upper bound.

## Sharing and league updates

- Import, copy, or open the current official version-6 Path of Exile Atlas URL.
  Unknown, duplicate, mastery, disconnected, over-budget, extended, and
  malformed payloads fail closed.
- Save up to 30 named local loadouts and compare exact shared/different nodes;
  no unsupported strategy score is invented.
- When a new validated league pack activates, current and saved loadouts are
  revalidated by node identity, connectivity, and budget, with incompatible
  nodes reported and dropped rather than silently remapped.

League Navigator, Build Lab, Craft of Exile, and the bounded Ctrl+D seller
snapshot remain intact. This release does not restore the retired full
official-trade-listings subsystem.
