# GloamCore 3.2.0

GloamCore 3.2.0 adds a deterministic Upgrade Assistant inside Build Lab on
Windows, with an intentionally limited saved-snapshot mode on Android and iOS.

## Verified desktop comparison

- Choose a saved baseline and either the current workspace or another saved
  candidate in a clear baseline-to-candidate flow.
- GloamCore serializes the complete selected PoB states, including tree specs,
  items, item sets, skills, configuration, and notes, then recalculates each in
  its own isolated local Path of Building process.
- A result is authoritative only when both calculations succeed, contain finite
  numeric outputs, and report the exact same verified PoB name, version,
  branch, platform, and runtime architecture.
- If either side fails, the build changes during calculation, the installed
  engine changes, or the passive-tree versions differ, no partial comparison
  is produced.
- Results expose baseline, candidate, and numeric difference alongside exact
  equipment, enabled-gem, passive-node, and PoB-warning evidence. They do not
  invent a score, rank, DPS value, effective hit pool, or recommendation.

## Mobile boundary

Android and iOS can import two exported GloamCore build snapshots and compare
their stored facts. Mobile cannot run Path of Building, so the interface marks
all numeric values snapshot-only, non-authoritative, and potentially stale and
directs users to verify the same pair on Windows.

League Navigator, Atlas Command Center, Craft of Exile, Build Lab, and the
bounded Ctrl+D seller snapshot remain intact. This release does not restore the
retired full official-trade-listings subsystem.
