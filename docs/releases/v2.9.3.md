# GloamCore 2.9.3

GloamCore 2.9.3 restores automatic live seller prices beneath the Ctrl+D
modifier editor without bringing back the retired listing subsystem.

## Price Checker

- Selected modifier changes automatically refresh a small public seller-price
  snapshot for supported rare, unique, and crafted-item Trade queries.
- Up to five sanitized price rows show the amount, seller name, and listing
  date directly beneath the modifier editor.
- Requests are restricted to fixed official Path of Exile search and fetch
  routes, bounded by strict payload and response limits, and cached briefly.
- Refreshes ignore stale responses and never require POESESSID or Path of
  Exile account authorization.

## Release integrity

- Craft of Exile remains present in the packaged desktop application.
- Release gates continue to reject the retired listing client and all exchange
  transport while permitting only the narrow current price-snapshot module.
- Native rare, unique, and crafted-wand smokes require real price rows and
  verify that the expanded overlay remains fully visible without clipping.
