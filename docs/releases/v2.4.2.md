# GloamCore 2.4.2

GloamCore 2.4.2 closes the last passive-card focus edge found during live-game
interaction testing.

## Highlights

- Keeps the normal Ctrl+D shortcut armed after clicking a checkbox, filter, or
  X inside the passive price-check card.
- Treats passive presentation as non-owning even if Electron briefly reports
  stale overlay focus while Path of Exile remains the Windows foreground app.
- Preserves the card's native input watcher instead of tearing it down before
  focus policy has classified the event.
- Retains reliable cold-start copying, double-corruption query logic, and the
  persistent isolated Wealthy Exile session from 2.4.1.
- Verified with real mouse and keyboard input against body armour, The
  Fledgling double-corrupted helmet, and a rare wand in the live game client.
