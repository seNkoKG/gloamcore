# GloamCore 2.9.1

GloamCore 2.9.1 adds Craft of Exile as an edge-to-edge desktop workspace and
refreshes the public project presentation around the complete current app.

## Crafting workspace

- Open the real Craft of Exile interface from the new **Craft of Exile** item
  in the desktop sidebar.
- The page fills the workspace, resizes with the window, and retains its own
  site-owned settings in a dedicated persistent browser partition.
- The embedded page has no preload, Node, Electron, filesystem, download, or
  clipboard-read access. Only first-party clipboard writes used by explicit
  export actions are permitted.
- A cached ads-only filter runs only on Craft of Exile pages, turns off during
  Patreon sign-in, and fails open if its filter engine is unavailable.
- Navigation stays on declared Craft of Exile and Patreon HTTPS origins.
  Allowlisted community links open in the system browser; every other popup or
  cross-origin navigation is denied.
- Craft of Exile and Wealthy Exile cannot be visible at the same time and do
  not share cookies, sessions, or storage.

## Project presentation

- Rewrote and reorganized the repository README to explain the current
  workflow, feature set, installation, data sources, security boundaries, and
  supported platforms.
- Updated the product website with the Craft of Exile workspace, current app
  capabilities, explicit trust language, and fresh 2.9.1 screenshots.

## Focused verification

The release audit covers the new browser boundary, renderer-to-main IPC parity,
desktop lifecycle, strict URL routing, permission denials, mobile external
handoff, release-version consistency, application tests, production builds,
and browser-level website verification.
