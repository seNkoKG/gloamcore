# GloamCore 2.3.4

GloamCore 2.3.4 makes the one-key price-check path smoother, fixes exact
pricing for double-corrupted uniques, and brings the real Wealthy Exile site
inside the Stash Wealth workspace.

## Highlights

- Embedded Wealthy Exile in a dedicated sandboxed browser session. Returning
  to Stash Wealth resumes the view automatically, and Wealthy Exile keeps its
  own persistent sign-in without exposing cookies, OAuth tokens, or stash
  responses to the app renderer.
- Added cached ads-only filtering for Wealthy Exile. Filtering is disabled on
  Path of Exile and Steam sign-in pages and fails open when no current or cached
  filter engine is available.
- Removed the blue Windows working-in-background cursor from Ctrl+D checks and
  native overlay interaction by completing GUI startup feedback as soon as the
  capture helper starts.
- Fixed double-corrupted unique pricing so both corruption implicits remain
  active in the official Trade query.
- Rebuilt the public product website with real captures, accurate
  trust boundaries, current release information, and direct installer,
  portable, and checksum links.

## Notes

- Wealthy Exile is an independent service and owns its Path of Exile account
  connection. Its terms and privacy policy apply inside the embedded view.
- The native overlay is intended for Path of Exile in Borderless or Windowed
  Fullscreen mode.
- Current Windows binaries are not Authenticode-signed. Download them only from
  this repository and use `SHA256SUMS.txt` when you need to verify a file.
- Installed builds can update through the stable GitHub release channel.
  Portable users update manually.
