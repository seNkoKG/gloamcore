# GloamCore 2.9.2

GloamCore 2.9.2 restores reliable main-skill selection and Path of Building
DPS recalculation in Build Lab.

## Build Planner

- The main socket-group selector now shows the group actually used for
  calculations, independently from the socket group currently open for edits.
- Enabled active gems remain selectable before a fresh local PoB calculation
  has populated the authoritative active-skill metadata.
- Selecting a main skill updates both `mainActiveSkill` and
  `mainActiveSkillCalcs`, matching Path of Building's saved calculation state.
- Utility skills such as Blood Rage can no longer trap the planner on a stale
  or disabled choice when a damage skill is available in the group.

## Verification

The regression fixture covers a Blood Rage plus Kinetic Blast group without
preloaded engine metadata. The complete planner, serialization, and packaged
PoB bridge suite passes, together with the production TypeScript and Vite
builds. Generated third-party notices are also left untouched when their
content is byte-identical, and the release gate validates actual staged,
unstaged, and untracked content instead of Windows stat-cache noise.
