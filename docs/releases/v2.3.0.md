# Ninja Lens 2.3.0

Ninja Lens brings one-key Path of Exile item checks, live economy context,
Build Lab, and the Player Toolkit together in one tray-first Windows companion.

## Highlights

- Hotkey checks now behave like Awakened's silent update: a stalled or
  incomplete clipboard read never replaces the previous card with an error.
  It simply keeps whatever was on screen. Users who want the old fail-closed
  card can enable **Legacy capture behavior** in Settings.
- Ctrl+D reveals the copied item before league discovery and stat hydration,
  so a cold league request can never make a valid check look unresponsive.
- While the overlay owns keyboard focus, the hotkey is not re-evaluated inside
  it (Escape and Ctrl+W return focus to the game). The capture gate also
  accepts text as soon as the leading "Item Class:" line lands, matching
  Awakened's completion gate.
- Market estimate rows paint progressively as each poe.ninja source arrives
  instead of waiting for the slowest request.

## Install

Download **Ninja-Lens-Setup-x64.exe** below and run the installer. The portable
executable is also available for users who prefer a standalone copy.

Windows binaries are not currently Authenticode-signed, so SmartScreen may
display an unknown-publisher warning. Download only from this release and use
`SHA256SUMS.txt` to verify the file when desired.

## Updates

2.2.8 was the first build connected to Ninja Lens's public GitHub update
channel. 2.3.0 is discovered automatically from that channel, downloaded in
the background when automatic checks are enabled, and installed only after
the user chooses **Restart & install**.

## Notes

- The native overlay is intended for Path of Exile in Borderless or Windowed
  Fullscreen mode.
- Seller rows are asking prices rather than completed sales; inspect the full
  Trade page before pricing a valuable item.
- Settings, watchlists, and saved workspaces remain local to the computer.
- Parity mode is the default; the legacy fail-closed card remains available
  through the "Legacy capture behavior" setting for troubleshooting.
