# GloamCore 3.4.5

GloamCore 3.4.5 corrects main-skill selection and Path of Building
recalculation in Build Lab, and removes incomplete orbit-ring fragments from
Atlas Command Center.

## Fixed

- The Build Lab stat rail now contains a compact main-skill dropdown.
- Selecting a skill in either the stat rail or Skills workspace updates both
  Path of Building skill-selection indices used by its display and calculation
  views.
- Imported output values are cleared as soon as the selected skill changes,
  preventing a new skill name from being paired with old or zero stats.
- When the verified local Path of Building engine is available, selecting a
  skill immediately recalculates the exact build and refreshes Combined DPS,
  Hit DPS, attack/cast rate, and the other engine outputs.
- Atlas orbit art now assembles all four rotations of Grinding Gear Games'
  official quarter-ring sprite, eliminating detached blue quarter-circle
  fragments while preserving official geometry.

## Verification

- Regression coverage proves that the same PoB build returns zero Combined DPS
  with Blood Rage selected and positive Combined DPS with Kinetic Blast
  selected.
- Planner serialization coverage verifies that both PoB main-skill indices are
  updated together and stale stats are invalidated.
- The complete test suite, production build, packaged PoB bridge smoke, and
  Windows price-check release smokes passed for the published artifacts.

Installed Windows builds can use **Settings → Check for updates**. Portable
Windows builds and mobile packages still require a manual replacement.
