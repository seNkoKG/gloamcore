# GloamCore 3.4.2

GloamCore 3.4.2 fixes the live seller-price refresh shown after selecting
modifiers in the native `Ctrl+D` price checker.

## Fixed

- Available Grinding Gear Games rate windows no longer create an unintended
  multi-second wait before every official Trade request.
- The newest checkbox state supersedes obsolete queued searches, and a stale
  search cannot spend its follow-up fetch request or delay the current query.
- A real official cooldown is still enforced locally and now retries
  automatically when it expires; an unresponsive renderer request also stops
  with a clear retry state instead of loading indefinitely.
- Native release QA selects Attacks per Second, Critical Strike Chance, Global
  Critical Strike Multiplier, and Explicit Physical Modifier magnitudes on the
  reported crafted wand. The release is rejected unless `4/10 STATS` remains
  visible with settled `PRICE / SELLER / LISTED` rows in the captured window.

The snapshot remains bounded to ten seller rows with a 30-second cache and the
complete query remains an explicit handoff to the official Trade website.
Craft of Exile remains intact, and the retired full official-trade-listings
subsystem remains absent.
