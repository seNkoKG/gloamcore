# GloamCore 2.6.0

GloamCore 2.6.0 makes the Build Planner read like an actual Path of Exile
loadout while preserving the local Path of Building engine as the calculation
authority.

## Highlights

- Replaces vertical item lists with a PoE-style equipment paper doll, weapon
  sets, flask row, jewel trays, imported alternatives, and detailed inspection.
- Uses trusted official Path of Exile CDN artwork supplied by character imports
  for equipment, gems, cluster jewels, Timeless Jewels, and Abyss jewels.
- Adds separate main socket-group and active-skill selectors plus Full DPS
  membership and per-gem enabled, level, and quality controls.
- Returns exact skill metadata and evaluated outputs from the installed Path of
  Building Community engine instead of guessing the selected skill or raw-value
  display conversion.
- Corrects sidebar presentation for critical multiplier, movement speed,
  suppression, block, recovery, Hit DPS, and Full DPS.
- Draws socketed jewel artwork directly into matching passive-tree sockets.
- Restores the complete imported planner workspace on restart while keeping it
  in the local OS profile and outside source control and release artifacts.
