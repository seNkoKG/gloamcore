# GloamCore 3.4.0

GloamCore 3.4.0 completes several high-value daily workflows without widening
the app's data or game-input boundaries.

## Unified command search

- Search native workspaces, economy categories, saved builds, saved Atlas
  presets, validated gems, official Atlas nodes, and already-loaded markets.
- Saved builds and presets open by exact local ID; direct sidebar navigation
  clears prior command targets.
- `Ctrl+P` opens command search inside the dashboard. The existing configurable
  global instant-search shortcut remains available while Path of Exile is open.

## Exact PoB progression and Trade handoffs

- Passive, skill, and item timelines come only from authored PoB specs and
  sets. No act, level, upgrade score, DPS, or defensive milestone is invented.
- Exact additions and removals are shown between authored stages.
- Official Trade opens only after a user click. Unique name/base identity is
  exact; rare and magic gear is explicitly labelled as a base-only search.

## Atlas Strategy Presets

- Add folders, tags, notes, filtering, and duplication to named Atlas trees.
- Import and export a bounded, validated GloamCore JSON bundle.
- Each approved league-pack migration reports incompatible node IDs per preset;
  graph, point, gateway, allocation, refund, and official URL rules remain
  deterministic and fail closed.

## Filters, recovery, and accessibility

- Save named item-filter profiles without changing the active game file,
  compare stable PoE rule identities, and stage a profile before **Save safely**.
- Immediate recovery restores require confirmation and create a before-restore
  checkpoint.
- Export and restore allowlisted workspace data with an automatic native
  recovery copy. Privacy-safe support bundles contain versions, booleans, and
  counts—not paths, names, copied items, cookies, or tokens.
- Native workspaces gain global text sizing, reduced motion, visible keyboard
  focus, accessible status colours, and explicit stable/preview update channels.

Craft of Exile, isolated ad-free Stash Wealth, and the bounded Ctrl+D seller
snapshot remain intact. This release does not restore the retired full
official-trade-listings subsystem.
