# GloamCore 2.3.2

GloamCore brings one-key Path of Exile item checks, live economy context,
Build Lab, and the Player Toolkit together in one tray-first Windows companion.

## Highlights

- Fixed the first-launch data migration introduced in 2.3.1: the packaged
  application stores its profile under the npm package name, so settings,
  watchlists, and saved workspaces are now carried over from both the old
  "PoE Economy Widget" product directory and the old `poe-economy-widget`
  package directory. Nothing already written by the new profile is overwritten.

## Install

Download **GloamCore-Setup-x64.exe** below and run the installer. The
portable executable is also available for users who prefer a standalone copy.

Windows binaries are not currently Authenticode-signed, so SmartScreen may
display an unknown-publisher warning. Download only from this release and use
`SHA256SUMS.txt` to verify the file when desired.

## Updates

2.3.2 is discovered automatically from the update channel, downloaded in the
background when automatic checks are enabled, and installed only after the
user chooses **Restart & install**.

## Notes

- The native overlay is intended for Path of Exile in Borderless or Windowed
  Fullscreen mode.
- Seller rows are asking prices rather than completed sales; inspect the full
  Trade page before pricing a valuable item.
- Settings, watchlists, and saved workspaces remain local to the computer.
- Parity mode is the default; the legacy fail-closed card remains available
  through the "Legacy capture behavior" setting for troubleshooting.
