# GloamCore 2.7.0

GloamCore 2.7.0 adds three native PoE 1 tools and finishes the Build Planner
fidelity pass. These features run inside GloamCore and do not require Scalpel.

## Highlights

- Adds Map Mod Check with 104 canonical modifier definitions, explicit local
  Good/Warn/Bad/Ignore rules, one-copy capture, and a temporary overlay.
- Adds a private PoE Event Log that safely follows `Client.txt`, handles
  partial UTF-8 writes and rotation, filters useful event families, and keeps
  at most 500 events in memory.
- Adds Cluster Back with installed PoB ordering, current Wiki spawn weights,
  official Trade stat IDs, exact affix/group constraints, Trade queries, and a
  copied-jewel verifier.
- Draws PoB's exact jewel-family socket overlays and Timeless Jewel radii,
  including Lethal Pride's Karui Large-radius treatment.
- Resolves exact item, flask, cluster, base-jewel, and Timeless Jewel artwork
  from PoE Wiki without embedding remote images in saved builds.
- Adds PoB-compatible skill-part, stage, mine, minion, item-set, and minion-skill
  selectors and preserves them through XML import, recalculation, and export.
- Removes Galaxy and migrates an old Galaxy workspace directly to Calculations.

## Independence and privacy

Map Mod Check, PoE Event Log, and Cluster Back are independent GloamCore
implementations. No Scalpel code, runtime, plugin, or installation is shipped
or required. Event contents remain in memory and are never uploaded or saved.

## Windows downloads

Download **GloamCore-Setup-x64.exe** for the normal installed build. The
versioned setup, portable executable, blockmap, updater metadata, and checksums
are attached to the same release.
