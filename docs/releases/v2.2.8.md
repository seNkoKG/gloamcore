# GloamCore 2.2.8

GloamCore brings one-key Path of Exile item checks, live economy context,
Build Lab, and the Player Toolkit together in one tray-first Windows companion.

## Highlights

- Press `Ctrl+D` over an item for a compact, roll-aware price check with live
  seller evidence and a complete official Trade handoff.
- Browse live poe.ninja markets with league filters, trends, liquidity context,
  watchlists, and local price alerts.
- Import, inspect, edit, compare, calculate, and export supported Path of
  Building builds in Build Lab.
- Build source-tracked stash and map regexes, edit filters, compare socket
  colours, and keep practical overlays in the Player Toolkit.
- Price-check modifier selection, ordering, bounds, labels, identity controls,
  and Trade serialization are regression-tested against the pinned Awakened
  PoE Trade 3.29.104 reference pipeline.

## Install

Download **GloamCore-Setup-x64.exe** below and run the installer. The portable
executable is also available for users who prefer a standalone copy.

Windows binaries are not currently Authenticode-signed, so SmartScreen may
display an unknown-publisher warning. Download only from this release and use
`SHA256SUMS.txt` to verify the file when desired.

## Updates

2.2.8 was the first build connected to the public GitHub update channel.
Earlier builds must install this release manually once. Future stable releases
are discovered automatically, downloaded in the background when automatic
checks are enabled, and installed only after the user chooses **Restart &
install**.

## Notes

- The native overlay is intended for Path of Exile in Borderless or Windowed
  Fullscreen mode.
- Seller rows are asking prices rather than completed sales; inspect the full
  Trade page before pricing a valuable item.
- Settings, watchlists, and saved workspaces remain local to the computer.
