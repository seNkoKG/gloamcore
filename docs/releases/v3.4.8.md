# GloamCore 3.4.8

GloamCore 3.4.8 is a reliability and usability release for Windows desktop and
compact layouts. The same responsive source improves browser/mobile layouts,
but this release publishes Windows x64 artifacts only. It keeps persisted data
recoverable, global search current, and expensive work off the initial startup
path.

## Improved

- Settings, Toolkit workspaces, and economy caches now enforce bounded payloads,
  serialize disk writes, migrate only verifiable cache identities, and preserve
  invalid files for explicit recovery.
- Global item search uses an incremental revisioned index with delta publishing,
  exact deduplication, stale-response protection, and Faustus market support.
- Major workspaces and game data load on demand, with visible retry paths for
  startup and runtime failures.
- Phone and compact-window navigation now provides a complete More menu,
  stronger keyboard focus and restoration, clearer empty states, larger touch
  targets, landscape handling, and durable Toolkit preferences.
- Market-pulse calculations require stronger sample evidence and retain source
  context while rejecting unstable outliers.
- CI now enforces high-severity dependency audits, mobile release metadata,
  Android build/lint/unit checks, and a dedicated manual Windows release gate.

## Verification

- The 134-file, 1,718-test suite completes at the 3.4.8 release identity,
  together with TypeScript and the production build.
- Dependency audits and the explicit unbuilt-mobile policy pass with no known
  high-severity vulnerabilities or falsely promoted mobile artifact.
- The packaged Path of Building engine and unique, rare, and wand Ctrl+D native
  smoke scenarios pass against the exact provenance-bound release executable.

Installed Windows builds can use **Settings -> Check for updates**. Portable
Windows builds require a manual replacement. No 3.4.8 Android or iOS package
has been built or published.
