# GloamCore 2.4.1

GloamCore 2.4.1 finishes the interaction and migration polish behind the new
identity.

## Highlights

- Keeps Path of Exile focused while the passive Ctrl+D card is visible,
  including clicks inside the card and X dismissal.
- Gives the first native item copy a guarded cold-start window while preserving
  the fast warm path and removing Windows startup-feedback cursor noise.
- Migrates an existing Wealthy Exile browser session even if the GloamCore
  profile was initialized before the upgrade, without overwriting newer data.
- Refreshes the GitHub README with the current product story, screenshots,
  direct stable download, shortcuts, privacy model, and upstream attribution.
- Keeps roll-aware unique modifiers, double corruptions, embedded ads-only
  filtering, and automatic Stash Wealth resume behavior intact.
