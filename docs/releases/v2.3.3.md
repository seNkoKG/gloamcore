# Ninja Lens 2.3.3

Ninja Lens brings one-key Path of Exile item checks, live economy context,
Build Lab, stash wealth tracking, and the Player Toolkit together in one
tray-first Windows companion.

## Highlights

- Added desktop Path of Exile OAuth support with PKCE for stash and character
  access. Users connect through the app; OAuth tokens are kept in the desktop
  profile and are never placed in renderer local storage.
- Added Stash Wealth with tab synchronization, poe.ninja valuation, snapshot
  history, wealth deltas, family breakdowns, and top-item views.
- Improved price-check startup by warming the bundled Trade catalog and league
  cache, sharing pending league requests, resolving stat data in parallel, and
  removing animated loading indicators from the initial state.
- Stabilized the native overlay focus handoff and close lifecycle.

## Notes

- OAuth application registration is handled by Grinding Gear Games. Only the
  application owner registers the public client; users authorize their own
  accounts from the desktop connect flow.
- The native overlay is intended for Path of Exile in Borderless or Windowed
  Fullscreen mode.
- Settings, watchlists, OAuth sessions, and saved workspaces remain local to
  the computer.
