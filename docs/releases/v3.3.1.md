# GloamCore 3.3.1

GloamCore 3.3.1 is a focused presentation and embedded-browser hardening
release. It keeps the verified Path of Exile logic from 3.3.0 intact.

## Clean Atlas workspace

- Official Atlas node sprites now scale proportionally with the current graph
  zoom instead of overlapping at the fitted overview.
- Wheel zoom is cursor-centred, search results focus a readable node, hit areas
  follow the visible sprite size, and the exact inspector floats over a full
  tree canvas like Build Lab.
- Atlas graph connectivity, point grants, shortest-path allocation, refunds,
  URL import/export, loadouts, comparisons, and league-pack migration are
  unchanged and remain covered by deterministic tests.

## Coordinated native themes

- League Center now uses GloamCore's graphite surfaces and semantic palette,
  with a line-style Compass icon matching the existing sidebar.
- Settings offers persisted Gloam Teal, Azurite Blue, and Ember Gold themes.
  Native market, League Center, Item Intel, Toolkit, Build Lab, and overlay
  surfaces share the selected palette. Craft of Exile and Stash Wealth remain
  site-owned browser surfaces.

## Stash Wealth ad regression

- The existing ads-only network filter remains enabled for Wealthy Exile.
- An origin-scoped cleanup now also removes the current Nitro side rails and
  Google advertisement frames after every document load and SPA remount.
- Authentication origins, cookies, downloads, permissions, and private page
  data remain isolated exactly as before.

Craft of Exile and the bounded Ctrl+D seller snapshot remain intact. This
release does not restore the retired full official-trade-listings subsystem.
