# GloamCore 2.9.0

GloamCore 2.9.0 is a rules-and-correctness release. Supported market, Trade,
build-planning, toolkit, desktop, mobile, and release paths were traced to their
current contracts, attacked with adversarial fixtures, and given fail-closed
regressions where a wrong answer would be worse than no answer.

## Correct pricing and Trade handoff

- Chaos/Divine values are never fabricated. Direct Chaos prices survive a
  partial snapshot; unavailable conversions remain visibly unavailable.
- Zero, missing, malformed, or stale market evidence cannot silently become a
  reliable estimate, mover, trend, or watch alert.
- Cluster Jewel selectors, Forbidden Flame/Flesh passives, and Foulborn identity
  produce exact official Trade filters or no Trade link.
- Unsupported in-app Trade search, exchange, and fetch transport is removed,
  including listing UI, caches, IPC, and packaged remnants.
- Copied text, roll edits, and the complete query plan remain local. Only an
  explicit user click opens the encoded filters on the official Trade website;
  GloamCore never calls its undocumented search, exchange, or fetch APIs.
- poe.ninja aggregates and documented Public Currency Exchange completed-hour
  observations from Faustus stay distinct, source-aged evidence. Neither is
  presented as a completed sale.

## PoB and toolkit correctness

- Build Lab accepts only Path of Exile 1 build and passive-tree version
  families; unsupported versions fail closed instead of being reinterpreted.
- Passive socket and override state, unknown spec children, and equipment
  weapon sets remain lossless. Current Cluster Jewel hashes declare format 2;
  legacy hashes are converted only with enough authoritative tree/socket data.
- The shipped regex pack contains 15,854 entries in 20 categories from three
  declared sources: pinned local Awakened PoE Trade base and stat packs plus
  current PoE Wiki map-modifier data. It is collision-checked against complete
  tooltip witnesses. Safe output is the default; compact output is experimental.
- Normal and Ruthless filters enforce their legal headers, actions, colour
  alpha, and filename extensions before writing.

## Removed rejected account integration

GGG did not approve GloamCore's OAuth application. Version 2.9.0 therefore
removes its complete OAuth, account-character, and native stash implementation:
UI, IPC, services, credentials examples, tests, and packaged remnants. This is
not hidden or bypassed. PoB XML/code import and local PoB calculations remain;
Stash Wealth still opens Wealthy Exile in its separately sandboxed site view,
where GloamCore never receives its OAuth tokens or stash responses.

## Platform and release safety

- Settings changes are validated and persisted atomically before native state is
  committed, with rollback and bounded retry on I/O failure.
- Event-log access requires the native file picker; renderer-supplied paths,
  symlinks, and non-files are refused.
- Focus-gated macros require an exact Path of Exile process/title pair and
  revalidate the same window immediately before input.
- Browser/mobile text imports have strict host, redirect, timeout, byte, UTF-8,
  credential, and referrer boundaries.
- Android and iOS generated projects are normalized and verified in CI; preload
  and main-process contracts plus packaged contents have bidirectional release
  gates.
- Economy snapshots are published through GloamCore's cache-aware static mirror
  rather than multiplying direct poe.ninja traffic from every installed client.
- Electron 43.3.0 carries the audited Windows DPI and crash fixes. Vite 8.2.1
  and Capacitor 8.5.0 align the browser and mobile release toolchains.

## Verification

The release gate includes the complete unit/integration suite, TypeScript and
production builds, native helper self-tests, dependency audits, live route and
schema probes, deterministic data hashes, Windows packaged PoB/UI smoke tests,
Android build checks, iOS Swift-package/Xcode checks in macOS CI, exact artifact
checksums, and post-publication download verification.

Windows executables are reproducible release artifacts but are not
Authenticode-signed; Windows may show a reputation warning.
