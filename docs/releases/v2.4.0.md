# GloamCore 2.4.0

GloamCore 2.4.0 completes the product's new identity without giving up the
settings, saved workspaces, price history, or Wealthy Exile session already on
the computer.

## Highlights

- Rebranded the Windows app, installer, portable build, updater, taskbar and
  tray surfaces, native helpers, Android/iOS projects, website, documentation,
  and GitHub release channel as GloamCore.
- Added first-launch migration for the previous desktop data directory,
  renderer storage keys, saved planner format, and isolated Wealthy Exile
  browser partition.
- Preserved the established Windows installer GUID so the existing update
  channel upgrades in place instead of installing a duplicate application.
- Replaced the inherited icon set with one original GloamCore mark across
  desktop, website, README, Android, and iOS assets.
- Renamed the reference-search workspace to Item Intel and removed redundant
  product-name labels from nearby app and website surfaces.
- Kept the 2.3.4 Ctrl+D smoothness, double-corruption pricing, embedded Wealthy
  Exile persistence, and scoped ads-only filtering intact.
