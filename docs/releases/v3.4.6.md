# GloamCore 3.4.6

GloamCore 3.4.6 is an Atlas presentation hotfix for the incorrect segmented
orbit rings shipped in 3.4.5.

## Fixed

- `OrbitN` art is no longer repeated as a decorative ring around every Atlas
  group.
- Neighboring nodes on the same orbit now connect with a clean short arc that
  follows the official graph geometry.
- Connections that cross the zero-degree angle boundary choose the short sweep
  instead of wrapping around the rest of the circle.
- Cross-group and cross-orbit connections remain straight, preserving a clear
  distinction between the two graph edge types.
- Atlas allocation, refund, point accounting, gateways, search, presets, and
  official URL import/export are unchanged.

## Verification

- Added focused regression tests for clockwise, anticlockwise, and
  angle-boundary arc geometry.
- Visually verified unallocated and allocated Atlas paths at Fit and zoomed
  views; detached quarter circles and segmented blue rings are absent.
- All 1,654 automated tests and the production build passed before packaging.

Installed Windows builds can use **Settings → Check for updates**. Portable
Windows builds and mobile packages still require a manual replacement.
