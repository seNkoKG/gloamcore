Under the hood

From hover to answer, locally.

One ordinary item copy stays on your machine — nothing is injected, scanned, or whispered. Here is the path every check takes.

1 · Press CtrlD

Ninja Lens performs exactly one Ctrl+C item copy and reads the text from your clipboard — no memory scans, no injection.

2 · Identify & plan

The parser classifies base, rarity, sockets, and modifiers against pinned Awakened-parity data, then builds a roll-aware search plan.

3 · Price with context

A poe.ninja identity estimate combines with live anonymous Trade listings, liquidity context, and visible stale-data labels.

4 · Verify on Trade

One click hands the mapped query to the official Trade site, or keeps TRADE in the compact overlay for a second look.

Get up and running in four steps

  1. 1Install — run the setup, or unzip the portable exe.
  2. 2Add to tray — launch Ninja Lens and leave it in the system tray.
  3. 3Set display mode — use PoE in Borderless or Windowed Fullscreen so the native overlay can attach.
  4. 4Check — hover an item and press CtrlD.
SmartScreen & verification

Windows binaries are not currently Authenticode-signed, so SmartScreen may show an unknown-publisher warning. Download only from this repository and verify the file before running it.

SHA256SUMS.txt 
certutil -hashfile "Ninja-Lens-Setup-x64.exe" SHA256

Prefer automatic updates? Installed builds check the stable GitHub update channel shortly after launch and install only when you choose Restart & install.

Privacy & safety

Private by design, bounded by trust.

Local-first

Memory-safe capture

Each CtrlD performs exactly one Ctrl+C item copy. No game-memory reads, no automation, no POESESSID.

FAQ

Questions, answered plainly.

Why does Windows show “Unknown publisher”?

Current builds are not Authenticode-signed, which is why SmartScreen flags them. Download only from the official GitHub repository and compare SHA256SUMS.txt before running — the checksum is published with every release.

Can I use a portable build and still update?

Portable builds are standalone: there is no background updater, so updating means replacing the executable from the latest release page. Installed builds use the automatic update channel instead.

Why do I need Borderless or Windowed Fullscreen?

The transparent overlay attaches to the native “Path of Exile” window. Windows cannot reliably place a normal desktop overlay above a game in exclusive fullscreen.

How does the price check work?

Press CtrlD over an item. Ninja Lens copies the item text, parses it locally, builds a roll-aware plan from pinned Awakened-parity stat data, and combines a poe.ninja estimate with anonymous live Trade listings. A TRADE button opens the mapped query on the official site for full verification.

Does Build Lab need anything installed?

Tree import and editing are local. Recalculating builds or importing supported PoE 1 characters uses a separately installed, verified Path of Building Community engine. Ninja Lens fails closed when that engine is missing or mismatched — it never invents calculated DPS.

Is Ninja Lens affiliated with GGG?

No. This product isn’t affiliated with or endorsed by Grinding Gear Games. Path of Exile names, artwork, and data belong to their owners; poe.ninja, Awakened PoE Trade, PoB Community, and PoE Wiki are independent projects that do not endorse Ninja Lens.

Is the source open?

The repository is source-available, not open-source. Official release binaries are provided for end-user installation; ask the maintainer before reusing project code.

Found a bug or have a request?

Open an issue on GitHub. Please include your Windows version, display mode, and a short description of what happened.
