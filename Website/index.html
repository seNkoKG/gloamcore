Clear boundaries

Useful without becoming intrusive.

Each feature states what it reads, which service receives data, and where the boundary lives.

Security policy ↗ Data provenance ↗
LOCAL

Copied item parsing

Ctrl+D performs one ordinary item copy and parses the resulting text locally. It does not inspect game memory or inject into PoE.

PUBLIC

Bounded Trade snapshot

Selected filters use fixed official Path of Exile search and fetch routes for a small public price snapshot. GloamCore asks for neither POESESSID nor Path of Exile account authorization.

BOUND

Two isolated site sessions

Craft of Exile and Wealthy Exile use different persistent profiles. Each site owns its login, cookies, storage, and private responses; neither profile is exposed to the app renderer or the other site.

OPEN

Inspectable releases

The source-available repository, release notes, installers, portable builds, updater metadata, and checksums are published together.

Before you install

Straight answers.

Limits and trust boundaries belong on the download page, not behind fine print.

What does Ctrl+D actually do?+

It performs one ordinary copy action on the hovered item, parses the copied English item text locally, and opens a compact result. Supported selected filters request a bounded public seller-price snapshot from fixed official Path of Exile Trade routes. It does not inspect game memory, inject into PoE, automate gameplay, request POESESSID, or send whispers.

Why does the overlay need Borderless or Windowed Fullscreen?+

Exclusive fullscreen can hide normal desktop overlays. Borderless or Windowed Fullscreen lets Windows keep the GloamCore overlay above the game.

Are the prices guaranteed?+

No. poe.ninja values are aggregate market context and Faustus values are completed-hour evidence. Missing Divine conversions remain unavailable, while weak or stale evidence cannot drive alerts. Open the exact query and verify valuable items on the official Trade website.

Do I need Path of Building?+

Most of GloamCore does not. Full Build Lab tree and recalculation workflows use a separately installed, supported Path of Building Community installation and fail closed when the engine is unknown.

What can the embedded websites access?+

Craft of Exile and Wealthy Exile run in separate sandboxed browser profiles without Node, Electron, filesystem, download, or clipboard-read access. Craft of Exile may write an explicit export to the clipboard. Ads-only filtering is scoped to each site and disabled on its sign-in hosts.

Installer or portable build?+

The installer supports the normal update path. New versions download in the background only when enabled, and installation waits for an explicit Restart & install action. Portable users replace the executable manually.

Why can Windows show an Unknown publisher warning?+

Current binaries are not Authenticode-signed. Download only from the official GitHub release and verify SHA256SUMS.txt when needed.

Is GloamCore open source or affiliated with GGG?+

No. The public repository is source-available under an UNLICENSED declaration, not open source. GloamCore is independent and is not affiliated with or endorsed by Grinding Gear Games.
